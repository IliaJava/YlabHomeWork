# YlabHomeWork

При запуске программа предлагает авторизироваться. По умолчанию есть 3 роли. 
Login:admin, password:admin123.
Login:manager, password:manager123.
Login:viewer, password:viewer123.
Admin обладает самыми большими правами, у каждой роли свои пункты меню для работы. Admin может добавлять, редактировать пользователей, смотреть метрики, делать аудит. Manager управляет товарами. Viewer просматривает.
По умолчанию есть несколько категорий товара.
Новые добавленные товары и пользователи сохраняются в файлах путем сериализации и при запуске программы читаются из файла(десириализация) для сохранения состоянии программы. Кеш огранизован через HashMap (стратегия LRU удаляется самый старый элемент, когда размер больше 100 записей). При поиске товаров, товары попадают в кеш, при чтении из кеша товар добавляется в конец. 
Поиск товара возможен по любому параметру товара(цена, категория....).
Метрики: аудит пользователей, кто и когда вошел, что делал когда вышел, время выполнения операции. Статистика попадания в кеш и промахи кеша.
